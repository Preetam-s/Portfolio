# Readme

## Requirements
Find the Requirements present in the requirements folder.
You'll need the following:
- pillow
- pyinstaller

To run directly, paste the commands in the CMD.

## Running the Script:

- Cmd at the location of the script.
- Paste this:
  - python pic_year.py
## Creating and Executing as .exe:
- Cmd at the location of the script.
- Paste this:
  - pyinstaller --onefile --windowed pic_year.py
- Locate the .exe under the dist folder 
  - dist/pic_year.exe
